## 🎯 学习路线（建议顺序）

1. **01-Linux基础**：零基础 → 命令实战 → 文本处理（grep/awk/sed）
2. **02-shell**：掌握 if / for / while / case，脚本自动化能力
3. **03-nginx**：静态托管 → 反向代理 → 负载均衡 → HTTPS → 安全防护
4. **04-排障案例**：用复盘沉淀"定位问题的思路"，比背命令更重要
5. **05-系统巡检**：日常巡检工具，作为运维日常工作手册

## 📝 维护约定

- **笔记命名规则**：
  - 带数字编号（`Shell01/02/03`、`Linux01/02/04`）= **学习主干**，数字 = 学习先后顺序
  - 无编号 = **练习 / 错题 / 补充知识**（如"Shell 流程控制错题笔记"）
- 新笔记放入对应主题文件夹，命名格式：`主题-要点.md`（**避免** `#` 开头、全角标点、多余空格）
- 同一主题的更新版直接覆盖旧版，不要产生 `(1)` `(2)` 副本
- 定期 review：合并重复内容、标注过时知识点
- 重要结论写进笔记后，随手 `git add . && git commit -m "更新xxx" && git push`
