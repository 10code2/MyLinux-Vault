好，下面是完整的部署流程，全部由你亲手操作。目标：用 Ansible 在 3 个节点上部署 Nginx 并写入各自的首页。

> 相关笔记：[[Ansible 基础运维完整笔记]]｜[[Alpine Nginx 部署脚本完整解析]]｜[[Ansible Nginx 部署全链路踩坑运维笔记]]

## 第 1 步：建项目 + 写 inventory

在 WSL 里执行：

```
mkdir -p /root/web-deploy
cd /root/web-deploy
```

创建 inventory（复制整段粘贴）：

```
cat > inventory <<'EOF'
[web]
node1 ansible_host=localhost ansible_port=2201
node2 ansible_host=localhost ansible_port=2202
node3 ansible_host=localhost ansible_port=2203

[web:vars]
ansible_user=root
ansible_ssh_private_key_file=/root/.ssh/id_ed25519
ansible_ssh_common_args='-o UserKnownHostsFile=/dev/null -o StrictHostKeyChecking=no'
EOF
```

测试连通：

```
ansible all -i inventory -m ping
```

三个节点都返回绿色 `"pong"` 再继续。

## 第 2 步：写 playbook

```
cat > deploy.yml <<'EOF'
---
- name: 最终修复版：统一配置部署 Nginx
  hosts: web
  become: true
  handlers:
    - name: 重载 Nginx 配置
      command: nginx -s reload
      when: nginx_process.rc == 0

  tasks:
    - name: 1. 安装 Nginx
      apk:
        name: nginx
        state: present
        update_cache: yes

    - name: 2. 确保站点根目录存在
      file:
        path: /usr/share/nginx/html
        state: directory
        mode: '0755'

    - name: 3. 写入自定义首页
      copy:
        content: "<h1>Hello from {{ inventory_hostname }}</h1>"
        dest: /usr/share/nginx/html/index.html
        mode: '0644'

    - name: 4. 写入统一站点配置（强制指定根目录）
      copy:
        content: |
          server {
              listen 80 default_server;
              listen [::]:80 default_server;
              root /usr/share/nginx/html;
              index index.html;
          }
        dest: /etc/nginx/http.d/default.conf
      notify: 重载 Nginx 配置

    - name: 5. 检测 Nginx 进程状态
      shell: pgrep nginx
      register: nginx_process
      failed_when: false
      changed_when: false

    - name: 6. 启动 Nginx（未运行时执行）
      command: nginx
      when: nginx_process.rc != 0

    - name: 7. 立即生效所有已触发的 handler（确保验证前配置已重载）
      meta: flush_handlers

    - name: 8. 验证服务返回 200
      uri:
        url: http://127.0.0.1
        status_code: 200
      changed_when: false
EOF
```

## 第 3 步：运行

```
ansible-playbook -i inventory deploy.yml
```

## 第 4 步：验证（通过 ansible 在节点内访问）

```
ansible web -i inventory -m command -a "wget -qO- localhost"
```

**预期结果**：三个节点分别返回 `<h1>Hello from node1</h1>`、`<h1>Hello from node2</h1>`、`<h1>Hello from node3</h1>`。

你先做，过程中任何一步报错或结果不符，把报错发我。全部跑通后，我再教你把它**重构成 Role**（企业里的标准写法），然后上传 GitHub。
